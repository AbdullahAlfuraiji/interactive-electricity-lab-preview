# Interactive Electricity Lab — Preview V1

Temporary public preview for colleague review / معاينة مؤقتة لمراجعة الزملاء.

Four bilingual, interactive educational modules:

1. Engineering Notation & SI Prefixes
2. Ohm’s Law
3. Series & Parallel Circuits
4. Series–Parallel Circuits

Open any lab from the home page and return with **All Labs / جميع التجارب**. The sequence is suggested, not required.

Static HTML with embedded styles, scripts and artwork. No framework, server API, analytics, CDN, external fonts or runtime dependencies. Individual lab files retain offline operation. To use directory navigation locally, serve this folder with any simple static HTTP server (for example, `python3 -m http.server 8000`).

Phone layouts stack controls and readings. Detailed component voltages/currents are available in the readable result panels below the circuit. The small-screen Ohm’s Law readouts mirror the original values.

This is a separate preview; it does not replace existing publicly shared projects.
